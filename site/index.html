Hire a team of bots that work on your Mac.

Give each bot a name, a role and a folder of its own, then talk to them in DMs, groups and threads. They run on the Claude and ChatGPT subscriptions you already pay for, with no API keys and no server.

What your bots can do

Work as a team
Your main bot knows everyone's role and hands work to the others. In a thread, anyone can pull another bot in with @name.
Use your computer
Each bot gets its own folder. It can read, write and run things there, and the files it makes land in the Library panel.
Connect your apps
Add Gmail, Slack, Notion, GitHub and more through MCP. Writes to accounts you own are blocked by default, so a bot can read your inbox but not send from it.
Ask before it acts
Messages and emails arrive as editable drafts. Approve once, always, or never, and every action is written to an activity log.
Run on a schedule
Ask for a morning briefing or an hourly inbox check. Routines also fire on webhooks, folder changes and GitHub pull requests.
Remember you
Bots keep a short memory of facts about you that you can edit, and you can import what another assistant already knows.
Talk out loud
Send voice memos or hold a spoken conversation. Speech is transcribed on your Mac.
Mix models
Pick any Claude model your plan offers, or a ChatGPT model through Codex, per bot.

Everything stays on your Mac

CharacterBot signs in through the Claude Code and Codex logins on this computer. Conversations, memories and files live in your Library folder, and secrets are encrypted with the macOS Keychain. There is no CharacterBot server to send them to.

Install

  1. Download the app. Get CharacterBot-arm64.dmg and drag CharacterBot to Applications.
  2. Open it the first time. The app isn't notarized yet, so right-click it and choose Open, or run xattr -dr com.apple.quarantine /Applications/CharacterBot.app.
  3. Sign in to Claude. Install Claude Code and log in, or connect in Settings. Add ChatGPT there too if you want ChatGPT bots and images.
  4. Say hello. Your first bot is waiting in the sidebar. Press ⌘N to hire another.

Questions

What does it cost?

The app is free. Bots use your own Claude subscription (Pro or Max) or an Anthropic API key, and optionally your ChatGPT subscription, so usage counts against those plans.

Which Macs does it run on?

Macs with Apple silicon. Intel Macs, Windows and Linux aren't supported yet, though you can try building from source.

Is the interface in English?

Not yet. Labels are in Korean. Bots answer in whatever language you write to them.

Can a bot send email or post to Slack as me?

Not by default. "Block writes to my account apps" is on, so bots can only read from apps signed in as you. Turn it off in Settings › Computer if you want drafts you approve to go out.

How do updates work?

Every change merged to the main branch is built and published as a new release. The download button on this page always points to the latest one.

Is this affiliated with Anthropic, OpenAI or xAI?

No. CharacterBot is an independent open-source project.
